# 47OS 98 — Лог принятых и отклонённых решений (ADR & Decisions Log)

В этом документе фиксируются ключевые архитектурные, дизайнерские и функциональные решения проекта **47OS 98** (`47Rubles.github.io`), а также обоснования, почему те или иные варианты были приняты либо отвергнуты.

---

## 1. Принятые решения (Accepted Decisions)

### 1.1. Клиентская архитектура без сборщиков (Vanilla Stack)
- **Суть решения**: Проект реализован исключительно на базе статических стандартов: HTML5, CSS3, Vanilla ES6 JavaScript без Node.js, Webpack, Vite или сторонних тяжелых библиотек.
- **Почему принято**: 
  - Гарантирует 100% совместимость с бесплатным статическим хостингом **GitHub Pages** без необходимости настраивать сложные CI/CD пайплайны.
  - Позволяет мгновенно открывать и тестировать сайт локально в любом браузере двойным кликом по `index.html`.
  - Устраняет риски поломки зависимостей и устаревания пакетов со временем.

### 1.2. Предзагрузка всех спрайтов и аудио в RAM на этапе BIOS
- **Суть решения**: Модуль `BootManager` на экране старта BIOS считывает манифест анимаций и до открытия рабочего стола декодирует в оперативную память браузера все 264 спрайта Неко-Арк и 25 звуковых эффектов. Прогресс отображается аутентичной зеленой шкалой в реальном времени.
- **Почему принято**:
  - Без предварительного кэширования браузер запрашивал кадры по сети по мере смены состояний персонажа, что вызывало белые вспышки, пропуски кадров и дерганую анимацию при первом запуске.
  - Звуки ударов и реплик теперь воспроизводятся с нулевой задержкой (0ms latency).

### 1.3. Фоновый интерактивный силуэт Неко (Спрайт 368) с большими овальными глазами
- **Суть решения**: В центр рабочего стола помещён полупрозрачный силуэт Неко-Арк (спрайт 368 из Melty Blood) с крупными белыми овальными глазами и вертикальными алыми зрачками. Зрачки в реальном времени отслеживают положение курсора мыши, глаза моргают каждые 5–10 секунд, щурятся при кликах по столу и пульсируют в такт музыке. Сам силуэт имеет лёгкую прозрачность (`opacity: 0.82`) и дыхание.
- **Почему принято**:
  - Обои стали уникальным живым арт-объектом, а не скучной статичной картинкой.
  - Овальные глаза и вертикальные кошачьи зрачки соответствуют каноничному дизайну персонажа.
  - Полупрозрачность гармонично вписывает тень в классический бирюзовый фон Windows 98.

### 1.4. Плеер через YouTube IFrame API со ссылкой на автора
- **Суть решения**: Музыка ("Great Cat's Village R" в джазовом ремиксе) воспроизводится через встроенный API официального YouTube-плеера с отдельной кнопкой прямого перехода на видео автора.
- **Почему принято**:
  - Полное уважение к труду автора ремикса и соблюдение авторских прав.
  - Не раздувает размер git-репозитория тяжелыми аудиофайлами.
  - Таймер проигрывателя строго привязан к событию `YT.PlayerState.PLAYING`, что исключает рассинхрон таймера и звука.

### 1.5. Защита артов водяным знаком «47R»
- **Суть решения**: Для галереи генерируются оптимизированные веб-версии изображений (`view_*.jpg`), в которые впечён полупрозрачный диагональный паттерн «47R». Также создаются легковесные превью (`thumb_*.jpg`). Оригинальные файлы автора остаются нетронутыми.
- **Почему принято**:
  - Защищает иллюстрации от несанкционированного скачивания и плагиата в высоком разрешении.
  - Галерея открывается мгновенно, не требуя одновременной загрузки нескольких тяжелых PNG-файлов.

### 1.6. Двухшаговая логика оценки репозитория (Звезда)
- **Суть решения**: Клик по ярлыку «Оценить_47OS» открывает ретро-окно с предложением перейти на страницу GitHub репозитория и кнопкой подтверждения «Я поставил звезду!». Золотая звезда зажигается только после клика по подтверждению. Добавлена кнопка «Сбросить отметку».
- **Почему принято**:
  - Технически браузер не имеет права проверить, нажал ли пользователь кнопку Star на стороннем домене GitHub.
  - Прежний вариант, где звезда автоматически становилась золотой при открытии окна, вводил пользователя в заблуждение.

### 1.7. Физика падения Неко с перемещаемых и закрываемых окон
- **Суть решения**: Таймер `checkSurface()` отслеживает, находится ли под ногами Неко поверхность активного окна. Если окно закрывается или перемещается из-под персонажа, Неко падает с гравитацией (кадры 265–267) и мягко приземляется на панель задач (кадры 268–273).
- **Почему принято**:
  - Устраняет визуальный баг «зависания Неко в воздухе» при манипуляциях с окнами.

## 2. Отклонённые решения (Rejected Decisions)

### 2.1. Шаблонные идеи для анимированного фона (Звездочки, банки Пилка, синтвейв-сетка, матричный дождь)
- **Статус**: Отклонено пользователем.
- **Причина**: Названы скучными, неоригинальными и заезженными. Вместо них реализован концепт мистического темного живого силуэта Неко-Арк, напрямую интегрированного в механику системы.

### 2.2. Маленькие круглые глаза на силуэте обоев
- **Статус**: Отклонено пользователем.
- **Причина**: Первоначальный вариант глаз был слишком мал и имел неправильную круглую геометрию, не соответствующую анатомии Neco-Arc. Заменён на аутентичные крупные белые овалы с вертикальными алыми зрачками.

### 2.3. Сплошная непрозрачность силуэта тени
- **Статус**: Отклонено пользователем.
- **Причина**: Глухой черный силуэт выглядел слишком грубо и перекрывал классическую бирюзовую палитру Win98. Добавлена прозрачность 18%, смягчающая интеграцию в фон.

### 2.4. Прямое хранение и воспроизведение музыки из локального MP3/WAV файла
- **Статус**: Отклонено.
- **Причина**: Неуважение к автору ремикса (нет счетчика просмотров и ссылки на оригинал), а также нецелесообразное увеличение размера git-репозитория.

### 2.5. Автоматическая установка золотой звезды без подтверждения
- **Статус**: Отклонено.
- **Причина**: Пользователь видел золотой ярлык еще до того, как открыл GitHub или поставил отметку проекту.

### 2.6. Старт системы без проверки готовности ресурсов в памяти
- **Статус**: Отклонено.
- **Причина**: Создавало белый шум, пропуск анимационных фаз и лаги при первом знакомстве пользователя с сайтом.
