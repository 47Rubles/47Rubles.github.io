# 47OS 98 — Персональный GitHub Pages 47Rubles

Вайбовый ретро-десктоп в эстетике Windows 98 с живым маскотом **Neco Arc**, CD-плеером с джазовым ремиксом `Great Cat's Village R`, интерактивным диалогом с 47R, защищенной галереей артов и карточками проектов (`docx-agent`, `Citatus`).

---

## 🚀 Как опубликовать на GitHub Pages (за 1 минуту)

1. Зайди на свой GitHub и создай новый публичный репозиторий с точным именем:
   ```text
   47Rubles.github.io
   ```
2. Открой терминал в папке этого проекта:
   ```bash
   cd "C:\Users\tchul\.gemini\antigravity\scratch\47Rubles.github.io"
   ```
3. Инициализируй git и отправь код:
   ```bash
   git init
   git add .
   git commit -m "feat: 47OS 98 initial release with Neco Arc"
   git branch -M main
   git remote add origin https://github.com/47Rubles/47Rubles.github.io.git
   git push -u origin main
   ```
4. Твой сайт мгновенно станет доступен по адресу:
   **https://47Rubles.github.io**

---

## 🎨 Как обновлять Галерею и накладывать водяной знак

В проекте есть встроенный скрипт для защиты твоих работ от кражи оригиналов:

1. Запусти скрипт:
   ```bash
   python tools/watermark.py
   ```
2. Он автоматически:
   - Берёт картинки из твоей папки со скетчами и артами.
   - Уменьшает разрешение для быстрой загрузки в вебе.
   - Запекает в пиксели мелкий полупрозрачный паттерн **«47R»**.
   - Генерирует `assets/gallery/gallery.json` для показа на сайте.

## ⚡ Особенности и фичи

- **Аутентичный Win98:** ретро-рамки, градиентные заголовки, кнопка «Пуск», системные часы, перетаскиваемые окна с z-index.
- **Neco Arc Daemon:** автономный маскот, бродит по экрану, следит за курсором, засыпает при простое.
- **Джазовый плеер:** играет `Great Cat's Village R (Jazz Remix)`. Если поставить музыку на паузу — Неко возмутится, прибежит к плееру и сама включит трек обратно!
- **Диалог с 47R:** кликабельное раскрытие реплик («Ты что тут делаешь?!») с полем ввода и отправкой записей в GitHub Issues.
- **Корзина с секретом:** при очистке корзины Неко кричит про потерянный Pilk.
